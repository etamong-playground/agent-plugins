# Curate verified references

Resolve the reader, topics, language and purpose before searching.
Prefer official documentation and original research for technical claims.
Use the provider's available search and page-reading tools; do not invent tool names or URLs from memory.

1. Search by topic and open each selected destination.
   Confirm that it loads, matches the intended subject and is accessible to the reader.
   Inspect figures before labeling a source as illustrated.
2. For each reference, record its title, destination, language, relevant subject and whether useful figures were actually observed.
   Keep the list focused; rank the most useful references first.
3. Identify missing topics and perform a bounded follow-up search.
   A login wall, unreadable script-only page, timeout or failed fetch is not a verified reference.
4. Deliver verified links with short annotations and explicitly state remaining gaps.
   If a user needs an unverified fallback, place it separately and label what was not verified.
   Never claim that every link was checked when a fallback was not.

Parallel research is optional and must use supported, authorized delegation.
Recheck findings against the actual source before relying on another agent's summary.

Example: “Find three official references for diagnosing macOS memory growth, with figures if available.”
Return links that were opened, explain which measurement each helps interpret, and do not manufacture a figure annotation.
